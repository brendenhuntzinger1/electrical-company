# Amp Club Electric website

Static site for a Tampa Bay electrical contractor (generators, panel replacement, EV chargers, Club membership).

- `index.html`: homepage (hand-written)
- `pages/*.html`: inner page content. Run `python3 build.py` to rebuild `generators.html`, `panel-replacement.html`, `ev-chargers.html`, `club.html`, `contact.html` with the shared header and footer.
- `styles.css`, `site.js`: shared styles and scripts

Placeholders to replace before launch: phone number, license number, prices, reviews, service area. The quote form is not wired up yet.
