# Volt Boys Electric website

Static site for a full-service Tampa Bay electrical contractor: residential service, panels, new construction (rough-in to trim-out), remodels, commercial, generators, EV chargers and the Volt Club membership.

- `pages/*.html`: page content
- `build.py`: shared header, footer, icons, phone and license; run `python3 build.py` to rebuild every page
- `styles.css`, `site.js`: shared styles and scripts

Placeholders to replace before launch: phone number, license number, prices, reviews, service area. The estimate form is not wired up yet.
